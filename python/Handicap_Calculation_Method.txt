 HANDICAP CALCULATION METHOD
Golf League Application

================================================================================

The system uses a progressive USGA method with the following steps:

STEP 1: CALCULATE SCORE DIFFERENTIALS
================================================================================
For each 9-hole score:
1. Double the score to get 18-hole equivalent
2. Calculate differential: (18-hole score - course rating) × 113 ÷ slope rating
   - Default course rating: 70 (par 35 × 2)
   - Default slope rating: 113

STEP 2: PROGRESSIVE CALCULATION BASED ON NUMBER OF SCORES
================================================================================

FOR 1-4 SCORES: BLENDING METHOD
- Blends current handicap with new score differentials
- Blend factors:
  * 1 score  → 0.2 blend factor
  * 2 scores → 0.4 blend factor
  * 3 scores → 0.6 blend factor
  * 4 scores → 0.8 blend factor
- Formula: (1 - blend_factor) × current_18_hole_handicap + blend_factor × avg_differential

FOR 5+ SCORES: USGA METHOD
1. Sort differentials from lowest to highest
2. Select number of scores to use:
   * 5 scores     → use 1 lowest
   * 6 scores     → use 2 lowest
   * 7-8 scores   → use 3 lowest
   * 9-11 scores  → use 4 lowest
   * 12-14 scores → use 5 lowest
   * 15-16 scores → use 6 lowest
   * 17-18 scores → use 7 lowest
   * 19 scores    → use 8 lowest
   * 20+ scores   → use 10 lowest

3. Calculate average of selected lowest differentials
4. Apply 96% factor: avg_differential × 0.96

STEP 3: CONVERT BACK TO 9-HOLE HANDICAP
================================================================================
- Divide the 18-hole handicap by 2
- Round to 1 decimal place

EXAMPLE CALCULATION
================================================================================
Player has 8 scores: [40, 38, 42, 39, 41, 37, 43, 40]

1. Double each score:
   [80, 76, 84, 78, 82, 74, 86, 80]

2. Calculate differentials:
   (80-70)×113÷113 = 10
   (76-70)×113÷113 = 6
   (84-70)×113÷113 = 14
   (78-70)×113÷113 = 8
   (82-70)×113÷113 = 12
   (74-70)×113÷113 = 4
   (86-70)×113÷113 = 16
   (80-70)×113÷113 = 10

   Differentials: [10, 6, 14, 8, 12, 4, 16, 10]

3. Sort differentials:
   [4, 6, 8, 10, 10, 12, 14, 16]

4. Use 3 lowest (for 7-8 scores):
   [4, 6, 8]

5. Calculate average:
   (4 + 6 + 8) ÷ 3 = 6.0

6. Apply 96% factor:
   6.0 × 0.96 = 5.76

7. Convert to 9-hole handicap:
   5.76 ÷ 2 = 2.88 → 2.9 handicap (rounded to 1 decimal place)
